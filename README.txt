KHAJAMOHIDEEN M — PORTFOLIO WEBSITE

HOW TO VIEW
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge or Firefox.
3. Keep the assets folder beside index.html so the résumé download works.

CUSTOMIZATION
- Edit index.html to update your text, experience, education and links.
- Edit style.css to change colours, spacing and typography.
- Edit script.js for the mobile navigation behaviour.

NOTES
- The portfolio content is based on the uploaded résumé.
- The site uses Google Fonts when an internet connection is available; system fonts are used as fallback.
- Check dates and details before publishing. The FACE Prep duration is shown as "2 Months" because the résumé does not specify exact dates.
